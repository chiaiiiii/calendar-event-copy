# 📅 カレンダー予定コピー

> みんな〜日報を書くとき、カレンダーを見ながら手入力してない〜？　それ、一瞬で終わります🫰

Googleカレンダーの予定タイトルを**箇条書きでワンクリックコピー**できるChrome拡張です。

## ✨ できること

- 日付を選んでボタンを押すだけ
- その日の予定が `・朝会` `・〇〇さんと面談` の形で一覧表示
- クリップボードにコピーして日報にそのまま貼り付け

## 🚀 導入手順

1. 右上の緑の「Code」→「Download ZIP」でダウンロード
2. ZIPを解凍する
3. Chromeで `chrome://extensions` を開く
4. 右上「デベロッパーモード」をオン
5. 「パッケージ化されていない拡張機能を読み込む」→ 解凍したフォルダを選択

## 💡 使い方

1. Googleカレンダーを開く
2. ブラウザ右上の拡張アイコンをクリック
3. 日付を選んで「予定を取得」
4. 「クリップボードにコピー」→ 日報に貼り付けて完了 🎉

## ⚠️ 注意

「日」表示モードで使うと一番確実に動きます。
